2. Welche Daten werden beim Besuch der Website gesammelt?

a) GitHub & Server-Logfiles Wenn du meine Website aufrufst, wird sie technisch über den Dienst GitHub bereitgestellt. Dies ist ein Service der GitHub Inc. (USA). Aus technischen Gründen erfasst GitHub automatisch Informationen, die dein Browser an den Server übermittelt. Diese sogenannten Server-Logfiles enthalten:

  • Deine IP-Adresse
  • Datum & Uhrzeit des Zugriffs
  • Die aufgerufene Seite oder Datei
  • Der Typ und die Version deines Browsers
  • Dein verwendetes Betriebssystem
  • Die Website, von der aus du zu meiner Seite gefunden hast.
Zweck: Diese Daten sind technisch notwendig, damit dir die Website überhaupt fehlerfrei, sicher und stabil angezeigt werden kann. GitHub speichert diese Daten in der Regel nur kurzzeitig.

b) Nutzung des localStorage deines Browsers
Um dir das Ablegen von Produkten im Warenkorb und einen reibungslosen Bestellvorgang zu ermöglichen, nutze ich den sogenannten „Local Storage“ (lokalen Speicher) deines Browsers. Hierbei werden technisch notwendige Daten lokal auf deinem G erät gespeichert. Diese Daten verbleiben auf deinem Gerät und werden nicht für Profiling- oder Marketingzwecke verwendet. Diese Daten werden nach einem erfolgreichem Kauf gelöscht.

Zweck: Diese Daten sind notwendig, dass du Pordukte in den Warenkorb legen kannst und dieser beim neu laden der Seite nicht verloren geht.

4. Wie läuft der Bestell- und Bezahlprozess ab? (Cloudflare & Stripe)

Wenn du in meinem Shop ein Produkt kaufst, müssen deine Zahlungs- und Bestelldaten sicher verarbeitet werden. Hierfür nutze ich eine Kombination aus zwei Diensten:

a) Sichere Weiterleitung über Cloudflare
Der eigentliche Programmcode für die Abwicklung des Bezahlprozesses liegt geschützt bei Cloudflare, einem Dienst der Cloudflare Inc. (USA). Wenn du den Checkout-Prozess startest, stellt dein Browser eine Verbindung zu Cloudflare her. Cloudflare sorgt als sichere Zwischenstation dafür, dass sensible API-Schlüssel und Programmcodes nicht öffentlich einsehbar sind. Dabei werden kurzzeitig technische Verbindungsdaten (wie deine IP-Adresse) an Cloudflare übermittelt. Zur Auswertung der Websitenutzung verwende ich Cloudflare Web Analytics. Dieser Dienst arbeitet datenschutzfreundlich, das heisst, es werden keine Cookies verwendet. Die Daten werden ausschließlich anonymisiert verarbeitet (u.a. Anzahl der Seitenaufrufe, Ladezeiten). Die Nutzung dient mir beispielsweise zur Erkennung sehr langer Ladezeiten. Weitere Informationen findest du in der Datenschutzerklärung von Cloudflare: Zur Datenschutzerklärung von Cloudflare.

Zweck: Erhöhung der Sicherheit und Schutz vor unbefugten Zugriffen auf die Shop-Schnittstellen.

b) Zahlungsabwicklung über Stripe
Die eigentliche Zahlung (z.B. per Kreditkarte) wird direkt über den Zahlungsdienstleister Stripe, bereitgestellt durch die Stripe Payments Europe Ltd. (Irland) bzw. Stripe Inc. (USA), abgewickelt. Wenn du bezahlst, gibst du deine Zahlungsdaten direkt im Zahlungsfenster von Stripe ein. Ich selbst habe zu keinem Zeitpunkt Zugriff auf deine vollständigen Kreditkartendaten. Stripe erfasst deine Zahlungsdaten, deine IP-Adresse sowie Details zu deinem Einkauf, um die Transaktion durchzuführen und Betrugsversuche zu verhindern.

Zweck: Vertragserfüllung und die sichere Abwicklung deines Kaufs.

Die USA gelten aus Sicht des Schweizer Datenschutzgesetzes als ein Land ohne angemessenes Datenschutzniveau. Um deine Daten dennoch bestmöglich zu schützen, stelle ich sicher, dass die Anbieter sogenannte Standardvertragsklauseln (Standard Contractual Clauses, SCC) der Europäischen Kommission abgeschlossen haben, die vom Schweizer Eidgenössischen Datenschutz- und Öffentlichkeitsbeauftragten (EDÖB) anerkannt sind. Zudem sind die meisten dieser Unternehmen unter dem Swiss-U.S. Data Privacy Framework zertifiziert, womit sie sich zur Einhaltung hoher Datenschutzstandards verpflichten.
