##  Über das Projekt
**Fabio3D** ist eine Plattform für den Verkauf von 3D-Druck-Produkten. Das Projekt setzt Vanilla JavaScript, CSS sowie serverlose Cloudflare Pages Functions in Kombination mit einer SQLite-Datenbank (Cloudflare D1).

---

##  Key Features

*  **Dynamischer Dark- & Light-Mode:** Animierter Wechsel zwischen hellem und dunklem Design auf den meisten Seiten.
*  **Produktvarianten & Live-Bestand:** Verschiedene Farb- und Modellvarianten mit automatischer Bestandsprüfung und Ausverkauft-Status.
*  **Integriertes Warenkorb- & Checkout-System:** Reibungsloser Einkaufsprozess dank Stripe-Anbindung für die Bezahlung.
*  **Bewertungssystem:**
  * Durchschnittsbewertung und prozentuale Sterne-Verteilung in einem Balkendiagramm.
  * Exklusiver **„Verifizierter Kauf“**-Badge, der vergeben wird, wenn das Backend bestätigt, dass dieser Käufer das Produkt gekauft hat.
  * Strukturiertes Feedback mit Titel, Kommentar sowie **Plus/Minus-Punkten**.
*  **Bestellübersicht:** Kunden können ihre vergangenen Bestellungen und die Sendungsverfolgung (Post) einsehen.
*  **Design für alle Geräte:** Perfekt für Desktop, Tablets und Smartphones.

---

## Verwendete Sprachen & Tools

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend & API:** Cloudflare Pages Functions (`/functions`)
* **Datenbank:** Cloudflare D1 (SQLite)
* **Icons & UI:** FontAwesome 6
